ClipVault — Windows10 剪贴板管理工具 需求文档
================================================

一、产品概述
------------
产品名称：ClipVault
技术栈：C# + WPF + SQLite
UI 风格：现代 Fluent 风格（ModernWpf.UI）
运行方式：系统托盘常驻，点击托盘图标弹出主窗口
支持内容类型：仅文本和链接（URL）

二、核心功能
------------

1. 剪贴板监听
   - 自动监听系统剪贴板变化（Win32 API AddClipboardFormatListener）
   - 仅捕获文本和 URL 类型内容
   - 自动去重：与最近一条内容相同则不重复记录
   - 最多保存 500 条历史记录，超出自动删除最旧的非收藏、非置顶记录
   - 防止自身触发：从 ClipVault 内部复制内容时，不产生新记录
   - 内容长度限制：单条内容超过 200kb 时跳过，不予记录
   - 应用单例：通过全局 Mutex 保证同一时刻只运行一个实例

2. 主界面 — 历史记录列表
   - 每条记录卡片显示：
     · 最多 2 行文本预览（超出显示省略号）
     · 来源类型标签（文本 / 链接）
     · 记录时间（相对时间：刚刚、5分钟前、昨天等）
     · 收藏图标、置顶标志
   - 单击卡片：立即将该条内容复制到剪贴板，并关闭主窗口（快捷复制模式）
   - 单击卡片右侧展开按钮（⋯）：展开详情面板，显示完整内容及操作按钮
   - 置顶记录始终显示在列表顶部，有特殊样式区分（蓝色左边框）
   - 取消置顶后，该记录按其原始时间归入普通列表
   - 统计行显示格式：过滤状态下显示"显示 xx 条 / 共 xx 条"，无过滤时显示"共 xx 条"
   - 列表无内容时显示空状态提示文字（如"暂无记录"或"未找到匹配内容"）
   - Esc 键：清空搜索框内容；再按一次：关闭主窗口

3. 搜索与过滤
   - 顶部搜索框，关键词实时搜索（内容模糊匹配）
   - 搜索框支持 Esc 键清空
   - 时间过滤器：全部 / 今天 / 最近7天 / 最近30天
   - 类型过滤：全部 / 仅文本 / 仅链接

4. 收藏
   - 对任意记录标记收藏（星形图标切换）
   - 收藏记录不受 500 条上限影响，不会被自动清除

5. 置顶
   - 将记录固定在列表顶部
   - 支持多条同时置顶，置顶记录之间按时间倒序排列
   - 可取消置顶；取消后按原始 created_at 时间归位到普通列表
   - 置顶与收藏可同时存在，互不影响；显示优先级：置顶 > 普通

6. 删除
   - 单条删除（详情面板中的删除按钮，需二次确认）
   - 批量清除（设置页提供"清除全部记录"选项，收藏记录默认保留，可勾选"同时清除收藏"）

7. 快捷键
   - 全局快捷键：Ctrl+Shift+V 唤出 / 隐藏主窗口（可在设置页自定义或禁用）
   - 主窗口内：
     · Enter：复制当前选中记录并关闭窗口
     · Esc：清空搜索框 / 关闭窗口
     · ↑ / ↓ 方向键：在记录列表中导航

8. 监听暂停
   - 托盘右键菜单提供"暂停监听"快速开关
   - 暂停时托盘图标变灰，提示当前不记录剪贴板内容
   - 适用于输入密码等敏感场景

9. 数据本地存储
   - 使用 SQLite 存储所有记录，启用 WAL 模式以支持后台线程写入与 UI 线程读取并发
   - 默认数据库路径：%AppData%\ClipVault\clipvault.db
   - 数据库路径可在设置页自定义（浏览按钮选择文件夹）
   - 修改路径时提示用户选择：迁移数据 或 从空白开始
     · 选"迁移"：将旧数据库复制到新路径，重新初始化连接，提示用户旧文件仍保留在原位
     · 选"从空白开始"：在新路径创建空数据库，明确告知用户旧数据仍保留在原路径
   - 设置文件：%AppData%\ClipVault\settings.json

10. 系统托盘
    - 应用启动后常驻系统托盘，不出现在任务栏
    - 托盘图标左键单击/双击：打开主窗口（在鼠标当前所在屏幕附近弹出）
    - 托盘图标右键菜单：
      · 打开主窗口
      · 设置
      · 暂停监听（开关项）
      · ──────────
      · 退出
    - 主窗口关闭按钮行为：最小化到托盘（不退出进程）
    - 主窗口记忆上次位置和大小，下次打开时恢复

11. 设置页
    - 开机自启开关（写注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run）
    - 全局快捷键自定义（输入框录制按键组合，可禁用）
    - 历史记录上限（数字输入框，默认 500，范围 100~2000）
    - 数据库文件路径（文本框 + 浏览按钮）
    - 修改路径保存时弹窗询问数据迁移方式
    - 数据导出（将所有记录导出为 JSON 文件）
    - 数据导入（从 JSON 文件导入，合并或覆盖现有数据）
    - 一键清空全部记录（可选"同时清除收藏"）

三、数据模型
------------

ClipItems 表（SQLite）：
  id          INTEGER  PRIMARY KEY AUTOINCREMENT
  content     TEXT     NOT NULL
  type        TEXT     NOT NULL  -- "text" | "link"
  created_at  TEXT     NOT NULL  -- 格式：yyyy-MM-dd HH:mm:ss
  is_favorite INTEGER  NOT NULL DEFAULT 0  -- 0/1
  is_pinned   INTEGER  NOT NULL DEFAULT 0  -- 0/1

settings.json：
  {
    "DatabasePath": "C:\\Users\\xxx\\AppData\\Roaming\\ClipVault\\clipvault.db",
    "MaxRecords": 500,
    "AutoStart": false,
    "GlobalHotkey": "Ctrl+Shift+V",
    "GlobalHotkeyEnabled": true,
    "WindowLeft": null,
    "WindowTop": null,
    "WindowWidth": 400,
    "WindowHeight": 600
  }

五、技术选型
------------

  功能            方案
  ──────────      ──────────────────────────────
  系统托盘        Hardcodet.NotifyIcon.Wpf
  剪贴板监听      Win32 AddClipboardFormatListener + HwndSource
  数据库          Microsoft.Data.Sqlite（WAL 模式）
  UI 风格         ModernWpf.UI
  列表虚拟化      VirtualizingStackPanel
  设置存储        System.Text.Json → settings.json
  开机自启        注册表 HKCU\...\Run
  全局快捷键      注册 RegisterHotKey Win32 API
  应用单例        全局 Mutex

六、关键逻辑
------------

1. 剪贴板监听
   - 通过 HwndSource 注册 WM_CLIPBOARDUPDATE 消息
   - 自动识别 URL（正则匹配 ^https?:// 开头）
   - 与最近一条内容相同则跳过
   - 内容超过 1MB 跳过
   - 写入数据库前设置内部标志位，屏蔽 ClipVault 自身复制操作触发的监听事件

2. 500 条上限（可配置）
   - 每次插入后检查非收藏、非置顶记录总数
   - 超出则删除最旧的非收藏、非置顶记录
   - 上限值取自 settings.json 的 MaxRecords 字段

3. 数据库并发
   - 启用 SQLite WAL 模式（PRAGMA journal_mode=WAL）
   - 后台监听线程写入，UI 线程读取，无需额外锁
   - 数据库操作异常时记录日志，不崩溃，向用户展示错误提示

4. 数据库路径变更流程
   - 用户选择新路径 → 点击保存
   - 弹窗："是否将现有数据迁移到新位置？"
   - 选"迁移"：File.Copy 旧数据库到新路径，重新初始化连接，提示旧文件保留在原位
   - 选"从空白开始"：新路径创建空数据库，提示旧数据仍在原路径可手动删除
   - 保存新路径到 settings.json

5. 应用单例
   - 启动时尝试创建全局 Mutex（名称：ClipVault_SingleInstance）
   - 已有实例运行时，向已有实例发送激活消息并退出当前进程

6. 窗口弹出位置
   - 根据托盘图标所在屏幕确定目标显示器
   - 窗口默认在任务栏附近弹出（右下角），保持在屏幕范围内
   - 用户手动移动窗口后，记忆新位置；下次打开恢复到记忆位置

7. 全局快捷键
   - 应用启动时调用 RegisterHotKey 注册
   - 快捷键冲突时提示用户并回退到默认值
   - 窗口已显示时再次触发快捷键则隐藏窗口（toggle 行为）
